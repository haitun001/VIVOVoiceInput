# VIVO语音输入

VIVO语音输入。默认快捷键是 **NVDA+Shift+V**，按住说话，松开停止。

## 使用前准备

您需要一个能正常录音的麦克风和良好的网络环境。您还需要具备一个有效的NVDA中文站账号。[点此访问NVDA中文站](https://www.nvdacn.com/)。

插件版本：0.2。NVDA版本：2026.1至2026.3。

## 安装与登录

1. 打开 `VIVOVoiceInput-0.2.nvda-addon`，按NVDA提示安装并重启。
2. 打开NVDA菜单 → 选项 → 设置 → VIVO语音输入。
3. 输入您的NVDA中文站用户名和密码，点击“登录”。

登录成功后，您的密码会通过Windows DPAPI加密保存，保护您的账户信息。

如果需要退出当前登录的NVDA中文站账号，请点击“退出登录”。退出后，插件会清理您保存的NVDA中文站账户信息。

## 选择麦克风

在插件设置的“输入设备”中选择您要使用的麦克风。“系统默认输入设备”会使用Windows设置的默认录音设备。

选择后点击“确定”或“应用”。若希望下次启动时继续使用，请保存NVDA配置，或开启“退出时保存配置”。

更换或插拔麦克风后，关闭整个NVDA设置窗口并重新打开，就能刷新设备列表。

## 开始语音输入

1. 将光标放在您要输入文字的位置。
2. 按住 **NVDA+Shift+V**，听到低沉的短提示音后开始说话。
3. 说完后，松开快捷键以及其他按住的按键。听到较高的提示音，就表示录音已停止。
4. 等待文字输入完成，再开始下一次语音输入。

每次最长可说60秒，到时会自动停止。NVDA键是您为NVDA设置的按键，例如Insert或Caps Lock。

说话和等待结果时，请留在当前输入位置。如果切换到别处，这次输入就会取消。

## 更改快捷键

如果您想换一个更顺手的快捷键，打开NVDA菜单 → 选项 → 按键与手势，在“VIVO语音输入”下找到“按住语音识别，松开结束识别”进行修改。

## 使用提示

- 启动NVDA时，如果所选麦克风不可用，插件会尝试使用系统默认麦克风，并读出提示。若仍不能录音，请检查麦克风的连接和Windows录音设置。
- 遇到问题时，NVDA会读出提示，您可以根据提示重试。
- 部分程序或输入位置可能无法接收文字，您可以换一个输入位置再试。
- 录音会发送给VIVO在线服务进行识别。
